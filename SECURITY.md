# Security Policy

## Supported Versions

We release security patches for the currently supported versions of our projects. Please refer to each repository's README for version support details.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | ✅ Yes             |
| Older   | ❌ No              |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue in any AbbyyDev project, **please do not open a public GitHub issue**.

### How to Report

1. **GitHub Private Vulnerability Reporting** (preferred): Use the [Security tab](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) in the affected repository to privately report the vulnerability.

2. **Contact a maintainer directly**: Reach out to a repository maintainer through their GitHub profile.

### What to Include

Please provide as much of the following information as possible to help us understand and address the issue quickly:

- Type of vulnerability (e.g., XSS, SQL injection, authentication bypass, etc.)
- Full paths to the affected source files
- Location of the affected code (branch, tag, or commit SHA)
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact assessment — what an attacker could achieve by exploiting this vulnerability

### Response Process

1. We will acknowledge receipt of your report within **48 hours**.
2. We will investigate and provide an initial assessment within **7 days**.
3. We will work with you to understand the scope and develop a fix.
4. We will notify you when the fix is ready and coordinate disclosure timing.
5. We will publicly credit you (unless you prefer to remain anonymous) in the security advisory.

## Security Updates

Security advisories will be published via [GitHub Security Advisories](https://github.com/advisories) for the affected repository once a fix is available.

## Scope

This policy applies to all repositories under the [AbbyyDev](https://github.com/abbyyDev) organization.
